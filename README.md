# gas-price-tracker

Description:
This project is a gas price estimator built with Python and a GUI interface. Users can enter a ZIP code, select their fuel level, compare gas grades, estimate trip costs, and view nearby gas station prices.

Language Used:
Python

Libraries Used:
Tkinter
Matplotlib
NumPy
Requests

Features:
- GUI gas estimator
- Real gas price data using API
- Fuel level selector
- Trip cost calculator
- Gas grade comparison graph
- Nearby gas station display
- Clear/reset function
